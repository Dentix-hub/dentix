FAQ / A FEW QUESTIONS

Before you open
your clinic account.

A few practical things you might want to know.

Are these actual product screenshots?+
Yes. The screenshots show the actual Dentix interface using fictional names, figures, and clinical examples. They contain no real patient records.
Do I need to install software on every device?+
Dentix is a cloud application that runs in a modern web browser. Sign in from a computer or tablet without setting up a local clinic server.
Can reception use Arabic while a dentist uses English?+
The application supports Arabic and English. Each user can choose the interface language that works for them.
What can I see in a patient’s record?+
You can review patient details, appointments, treatment history, the dental chart, payments, and the remaining balance.
How do I start?+
Choose “Create Clinic Account” and complete the registration form. If you already have an account, choose “Log in” to return to the application.
