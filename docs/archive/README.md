# Dentix Documentation Archive

This directory is for historical/obsolete documentation that has been safely retired from active navigation.

## Move criteria

A document may move here only when all are true:

1. It is classified `HISTORICAL` or `OBSOLETE` in `docs/product/DOCUMENTATION_CLASSIFICATION.md`.
2. Inbound repository references have been checked.
3. Active links are repaired.
4. A canonical replacement exists for any current-truth content it previously carried.
5. Useful provenance/date/status is preserved.

## Plan 01 decision

No bulk move was made during Plan 01. The repository contains many implementation plans and cross-references, and the audit did not establish a complete safe reference graph for mass relocation. Classification is therefore the first archive step; future moves should be small, reference-checked batches.

Do not delete historical evidence merely to make the repository look cleaner.
